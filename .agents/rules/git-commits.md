# Regras para Git Commits

- Todas as mensagens de commit devem ser escritas obrigatoriamente em português (pt-BR).
- Recomenda-se o padrão Conventional Commits com a descrição em português, por exemplo:
  - `feat: adiciona nova seção de destaques`
  - `fix: corrige alinhamento no cabeçalho`
  - `style: atualiza espaçamento e cores`
  - `docs: atualiza documentação do README`
  - `refactor: reorganiza funções utilitárias`
